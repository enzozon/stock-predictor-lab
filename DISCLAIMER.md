# AVISO LEGAL (DISCLAIMER)

Este projeto é **exclusivamente educacional**. Foi construído como exercício de
engenharia de software e machine learning aplicado a séries temporais financeiras.

- **NÃO é recomendação de investimento.** Nenhuma saída deste sistema (ranking,
  score, ordem simulada) deve ser interpretada como sugestão de compra ou venda
  de ativos reais.
- **NÃO executa ordens reais.** O bot opera apenas em modo *paper trading*
  (simulação com dinheiro fictício). Não há integração com corretoras.
- **Modelos de predição de preço têm poder preditivo baixo e instável.**
  Resultados de backtest não garantem resultados futuros; mesmo backtests
  rigorosos sofrem de vieses (sobrevivência, seleção de período, custos reais
  subestimados).
- Investir envolve risco de perda. Procure um profissional certificado antes de
  tomar decisões financeiras.
